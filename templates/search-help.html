How do I...? for Editors

No guarantees are made that this tool will be maintained.

This is an experimental tool hosted on Toolforge. No additional personal data is collected by this tool per the Cloud Services Terms of Use.

This tool is a new prototype for searching the Help and Policy namespaces on (English) Wikipedia.

It compares the results from existing Search with natural-language search of three different corpora:

-- Help: all pages in the Help namespace.

-- Question bank: all subpages from the Help Desk, Teahouse, and FAQs.

-- Policies/Guidelines: all Policies, Guidelines, and Manual of Style pages.
